# Plecări Security Policy
#
# If you discover a security vulnerability on plecari.com,
# please report it responsibly to security@plecari.com.
#
# We commit to:
# - Acknowledging receipt within 48 hours
# - Investigating and responding within 14 days
# - Not pursuing legal action against researchers
#   who act in good faith
#
# In scope: plecari.com and all subdomains
# Out of scope: third-party affiliate platforms linked from the site
#
# We do not currently offer a bug bounty program.
# Responsible disclosure is appreciated and credited.
